Countdown Numbers Solver

An open-source JavaScript solver for the Countdown numbers round. Enter six numbers and a target: it returns the shortest exact working, or the closest number you can reach. The code is on GitHub under the MIT licence.

    How it works

    The solver uses iterative deepening. It tries every one-step answer, then every two-step answer, and so on, so the first exact match uses the fewest operations. Every step must give a positive whole number, and each starting number is used at most once, as on the show.

    const solve = require('./solver.js');
solve([25, 50, 75, 100, 3, 6], 952);
// { value: 952, distance: 0, steps: [...] }
